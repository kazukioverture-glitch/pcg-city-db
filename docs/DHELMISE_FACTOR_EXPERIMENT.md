# ダダリン：平均52枚から勝因候補を検証する

参照：W01〜W04（2026-09-21〜2026-10-18）、2026-10-18 07:31 JST時点の収集スナップショット。

## 研究の問いと限界

目的は「よく採用される52枚」と好成績の構築との差を検出し、好成績と関連するカードを特定して次の独立データで検証すること。Top16入賞者に限定されているため大会参加者全員の勝率は計測できない。対面、プレイヤー実力、プレイング、先後、カード枠の競合も完全には除去できない。

- 主流群：ヤバソチャ1〜2枚＋通常ノココッチを採用するダダリン系144件。ノココッチexの有無は統合。
- 比較基準：[`dhelmise_consensus.json`](../data/deck_library/dhelmise_consensus.json) の19種類52枚。最頻枚数まで90%以上一致する厳密コアは9種類28枚。
- 成績分析：順位1・2・3×2・5×4・9×8の16枠が揃った大会のみ使用し、Top16内でTop4へ進んだかを主指標とする。
- 再現可能な探索結果：[`dhelmise_card_factors.json`](../data/deck_library/dhelmise_card_factors.json)。基準枚数より少ない／同じ／多い群、採用有無別Top4、週別の集計、週およびノココッチexで層化したCMH近似、多重比較BH補正を含む。
- データから選んだ仮説なので探索統計のp値を確証と扱わない。今後独立した週の結果、または対面を統制した対戦で事前に規定した指標を評価する。

## 最初の1枚交換実験：シェイミ ⇄ キチキギスex

ベースAは公式の[2026-10-04 シニアTop4 60枚](https://www.pokemon-card.com/deck/confirm.html/deckID/cccYxG-QTTCAJ-88x8Da)（イベント1115585）。52枚共通基準をすべて満たしているため比較元として選ぶ。

- **A（実績あり）**：共通59枚＋シェイミ1枚＝60枚。「はなのカーテン」でルールを持たないベンチポケモンをワザのダメージから保護する。
- **B（検証用・未実績）**：共通59枚＋キチキギスex1枚＝60枚。「さかてにとる」による、前の相手の番にポケモンがきぜつした場合の3ドローを利用する。exを倒されると相手にサイド2枚を取られるリスクがある。
- どちらも標準の同一60枚構成となるよう、最後の1枚以外は**絶対に変更しない**。公式リストと実績はAのみであり、Bを実績構築と誤認しない。

## 観察データの追加検討

実際に入賞した別構築同士をマッチングする場合、「週」および「ノココッチex採否」をそろえても、シェイミとキチキギスex以外のカードに残差が存在する。これは**59枚を固定した試験ではない**。傾向検証には使えても、カード1枚の因果効果とみなさない。

## 対戦試験の記録

| 項目 | 内容 |
|---|---|
| deck_variant | A / B |
| date, opponent_archetype | 対戦日時と相手デッキ |
| play_first, result | 先後と勝敗 |
| prizes_taken, prizes_lost | サイド取得・取られた枚数 |
| knockout_turn | きぜつのタイミング |
| curtain_prevented | シェイミが保護したポケモンと推定防御ダメージ |
| flip_over_cards_drawn | キチキギスexの特性を使った回数・引いた枚数 |
| liabilities | ポケモンexを狙われてサイド2枚を取られたか |
| notes | 特定カードが機能した／腐った場面、合理的な反実仮想 |

可能ならA/Bをランダムに選び、対面と先後を層化する。最初の少数戦は実行可能性の確認とし、有意差を宣言しない。独立したW05以降のシティリーグでも同じ事前仮説を検証する。

## 保護する範囲

元の大会DB、60枚ソースデータ、W01/W02 FINALと予測ログは不変。分析スクリプトが更新するのは派生ファイルのみ。

## W05〜W08の独立検証を事前固定

- **凍結した研究基準**：`data/research/dhelmise_hypothesis_v1.json`。W01〜W04の144件、共通52枚、厳密コア28枚、ソースSHA、検証条件を含む。**更新時も上書きしない**。
- **将来データ**：W05〜W08（2026-10-19〜11-15）。この期間に入った結果はベースの作成や仮説選定に再利用しない。
- **事前定義した一次比較**：キチキギスex採用・シェイミ非採用 vs シェイミ採用・キチキギスex非採用。主指標は、完全16枠の大会においてTop16からTop4へ進出した割合。Fisher両側正確確率検定を記録する。
- **補助検証**：週とノココッチex採否の層化解析、デッキコードの重複、共通52枚からの増減。主解析の母集団は変えない。
- **判定停止条件**：いずれかの群が10件未満、W05〜W08の週データが揃わない、結果取得監査が未完了のときは「不十分／暫定」の表示にとどめる。p値が0.05を下回るだけでは因果効果と呼ばない。
- **自動報告**：`python -m analysis.dhelmise_holdout`、生成先 `data/deck_library/dhelmise_holdout_v1.json`。W05の前は`status=not_started`。W05以降は有効な週の結果だけを追加する。

W05以降に通常の共通ベースを再集計しても、上記の凍結研究基準と独立検証には反映しない。差が生じた場合は「新しい平均と、旧ベースからの予測」を明示的に分離する。
