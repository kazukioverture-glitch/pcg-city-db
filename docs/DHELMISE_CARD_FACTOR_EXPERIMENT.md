# ダダリン共通ベースからの勝因仮説検証（探索版）

基準：2026-10-18 07:31 JST のデッキライブラリ（W01〜W04）。この文書は検証計画であり、「採用カードが勝因である」と主張するものではない。

## ゴールと検証対象

- ベース母集団：ヤバソチャ1〜2枚＋通常ノココッチ採用のダダリン型144入賞構築（ノココッチex採用有無を統合）。
- [共通ベース](../data/deck_library/dhelmise_consensus.json) は19種類52枚。うち同一枚数まで90%以上一致する厳密コアは9種類28枚。
- [カード別探索統計](../data/deck_library/dhelmise_card_factors.json) で各カードの分布とTop4進出の関連を評価。順位の比較は全16枠を確認できた大会の主流型119件に限定する。
- 目的変数は **「既にTop16入りしたデッキがTop4に進出したか」**。参加者全体の勝率・因果効果ではない。
- 因果解釈にはプレイヤー・対面・先後・環境変化・デッキ内カードの枠競合による交絡がある。探索段階の多数の検定に補正をかける。**p値が小さいから採用するのではなく**、独立週で再現し、可能なら同一59枚を固定したA/Bで検証する。

## 検証仮説の優先順位

1. **キチキギスex**：119件中、採用33件のTop4率12/33、非採用86件は15/86。週ごと・ノココッチex有無で層化し、再現性を調べる。機構として「相手の番に自分のポケモンがきぜつした後に山札3枚を引く」ことで復帰できる可能性がある。ただしシェイミのような防御カードと役割が異なる。
2. **シェイミとキチキギスexの枠交換**：シェイミ採用67件のTop4率は11/67、非採用52件は16/52。2枚の同時採否別に分けた4群の件数と成績を保存。シェイミ（特性「はなのカーテン」）はルールを持たないベンチへのワザダメージを遮断するため、ドラパルト等の広域打点への価値があり、総合成績だけで廃止しない。
3. **グラビティーマウンテン**：採用29件のTop4率10/29、非採用90件は17/90。2進化ポケモンの最大HPを30下げる効果が、対面によって有利・不利を分ける可能性。別スタジアムとの競合を踏まえ、まず相手の型別に評価する。
4. **共通カードの枚数差**：ボスの指令4枚、夜のタンカ3枚以上、ジュペッタ4枚、なかよしポフィン2枚以上など。ベース52枚の枚数をそのまま固定して因果を推定しない。

## 観察記録の最低要件

- A/Bの選択をランダム化し、可能なら同じ対面の両先後で偏りが少ないよう対戦を配分する。同一相手への連続対戦は独立標本として過信しない。
- 対面、先後、結果、サイド推移、倒された対象・ターン、キチキギスexの特性が何回使えたか、シェイミが防いだダメージの回数、サイド2枚を与えた場面を記録する。
- 初回の30戦ずつは操作・マッチアップごとの実行可能性の確認とし、有意差確定には使用しない。勝率差の確認に必要な対戦数は事前の効果量・検出力設計で再設定する。
- W05以降の大会結果は、W01〜W04で探索した仮説を評価する将来データとして保持する。後から選んだ別仮説の検証にも同じ週を再利用するときは探索扱いに戻す。
